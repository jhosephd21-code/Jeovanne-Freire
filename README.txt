Arquivos:
- index.html: estrutura do site
- style.css: estilos e layout responsivo
- script.js: menu mobile, ano automático e interação do formulário

Como abrir no VS Code:
1. Extraia o arquivo ZIP.
2. Abra a pasta extraída no Visual Studio Code.
3. Abra o arquivo index.html no navegador. Se tiver a extensão Live Server, clique com o botão direito em index.html e escolha "Open with Live Server".

Personalização:
- Edite os textos em index.html para incluir formação, experiência, cursos e projetos reais.
- Para o formulário abrir o e-mail correto, abra script.js e substitua SEU-EMAIL-AQUI pelo endereço de contato.
- O formulário usa mailto e não salva nem envia dados para um servidor.
